### 이번 주 배운것
- 만든 함수는 반드시 =를 통해 받아야 변수에 담긴다.- 반만 맞은 return으로 결과를 돌려주는 함수만 
- 변수는 작업대위의 자재, 파일은 창고
- ()=실행버튼, 이름만쓰면 공구를 가리키기만 하고, ()를 붙여야 공구가 사용된다.
- 받을 상자 = 공구이름(재료)
